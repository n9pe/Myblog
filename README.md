# Marginalia — a Jekyll blog starter

A simple, distinctive blog template. You write posts as markdown files;
GitHub Pages builds and hosts the site for free. No terminal, no build
tools required.

See the full setup walkthrough in the chat where this was generated, or
follow these steps:

1. Create a free GitHub account and a new **public** repository.
2. Upload every file in this folder to that repository (drag-and-drop
   on the GitHub website works fine).
3. In the repo, go to **Settings → Pages**, set the source to the
   `main` branch, and save. Your site will appear at
   `https://yourusername.github.io/your-repo-name` within a minute or two.
4. Open `CNAME` and `_config.yml` in the GitHub web editor and replace
   the placeholder domain with your real one.
5. At your domain registrar, point your domain at GitHub Pages (see
   the DNS instructions in chat).
6. To write a new post, copy a file in `_posts/`, rename it with
   today's date, and edit the title/content. Commit it — the live site
   updates automatically.

## Local preview (optional, only if you install Ruby/Jekyll later)

```
bundle install
bundle exec jekyll serve
```
